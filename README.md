# Cube Rhythm 2
在Minecraft中实现音游

本项目完全使用Skript及其附属编写，对应服务端内plugins/skript/scripts目录

## 跟1有什么不一样？
1. 基于1.21.11制作！
2. 重新设计了UI与交互！
3. 改进了操作方式，使用A/S/D键击打音符，更符合游戏规则的输入！
4. 资源文件都在服务端！服务端自动打包资源包，支持封面导入与显示！
5. 由服务端控制音频播放，支持预加载和任意位置开始，方便了音频对齐！
6. 内置编辑器支持即时播放与调整，无需其他软件辅助对音！
7. 音符渲染全发包实现，不再依赖实体与自增Timer，播放时占用腰斩！
8. 废除了.sk谱面读取，加载瞬间完成，谱面格式更直观！
9. 优化了每种音符的空间判定，Flick改为即时判定，更符合直觉！
10. 未来将支持接入Net实现谱面共享、分数上传等功能，敬请期待！
